An ultra-luxurious, architectural-grade e-commerce storefront for **AURA Studio** (luxury engineered phone cases, modular MagSafe accessories, and aerospace-grade phone armor).

---

## 📱 Included Screens & Customer Journey

1. **[Homepage](./homepage_aura_studio/code.html)**
   - Editorial hero presentation with flagship case highlight (*AeroShield Obsidian*).
   - Curated discipline category showcase.
   - Bestseller matrix with interactive swatches and quick add-to-bag.
   - Material engineering breakdown and customer editorial reviews.

2. **[Shop All / Catalog](./shop_all_phone_cases_collection/code.html)**
   - Faceted device filtering (iPhone 16 / Galaxy S24 / Pixel).
   - MagSafe compatibility badges and active filter pills tray.
   - Dynamic 3-column / 4-column compact grid switcher.
   - Tabular sort and live catalog metrics counter.

3. **[Product Detail Page (PDP) — ArmorShield Pro](./aura_armorshield_pro_product_detail_page/code.html)**
   - 5-angle studio macro gallery with interactive preview thumbnails.
   - Device model and tactical finish swatch selectors (*Titanium Graphite, Frost Clear, Matte Obsidian*).
   - Technical certification callouts (MIL-STD-810G 13ft laboratory drop rating).
   - MagSafe accessory bundle builder with live discount calculator.

4. **[Shopping Bag & Frictionless Checkout](./shopping_bag_checkout_aura_studio/code.html)**
   - Dynamic free worldwide express shipping milestone progress bar.
   - Real-time line item quantity adjustments and subtotal recalculation.
   - MagSafe add-on carousel & coupon code validator.
   - Express checkout accelerators (*Apple Pay, Shop Pay, Google Pay*).

---

## 🎨 Design Language: Atelier Tech Luxe

- **Purity of Surface:** Off-white warm canvas (`#FBFBFD`) juxtaposed against deep obsidian black (`#0D0D11`).
- **Engineered Restraint:** Controlled corner radii (`0.5rem` to `1.5rem`), hairline borders (`#E8E8ED`), diffused ambient shadows.
- **Typography:** Strict geometric tracking with *Plus Jakarta Sans*.

Full token specifications available in [`atelier_tech_luxe/DESIGN.md`](./atelier_tech_luxe/DESIGN.md).

## ⚡ Quick Start

### Option 1: Open Directly
Double-click `index.html` to open the interactive prototype hub in any web browser.

### Option 2: Run Local Server (PowerShell)
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Then visit **http://localhost:3000** in your browser.
